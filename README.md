# Lakehouse на Trino, Iceberg и MinIO

Прототип тестового задания системного аналитика. TPC-H проходит через Raw и Data Vault 2.0 до двух витрин. Один дашборд Superset показывает бизнес-метрики и результаты контроля качества по каждой попытке загрузки.

## Запуск и проверка

1. Подготовьте Docker и локальный `.env` по [руководству по развёртыванию](docs/deployment.md).
2. Из корня репозитория выполните `make up`, затем `make demo` на чистом проекте. Для просмотра контрольных данных после прогона выполните `make evidence`.
3. Запустите профиль `bi` и импортируйте [дашборд Superset](superset/lakehouse-dashboard.zip). [Инструкция ручной проверки](docs/manual-verification.md) показывает, как повторить каждый шаг в терминале, Trino CLI, MinIO и Superset.

Посмотреть вкладки: [Качество данных](docs/superset-dq.png) · [Бизнес-аналитика](docs/superset-business.png).
