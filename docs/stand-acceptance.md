# Программа и методика испытаний стенда

## Цель и предусловия

Проверить требование **STAND-01** из пункта 1 задания — развернуть стенд на основе Trino, Apache Iceberg и MinIO. Нужны Docker Engine с плагином Compose, локальный `.env`, образы сервисов и свободные порты. Команды выполняются в корне репозитория.

## Сценарии испытаний

| Сценарий | Методика | Критерий |
|---|---|---|
| STAND-01-1. Запуск | `docker compose config --quiet`, затем `docker compose up -d --wait --wait-timeout 180` и `docker compose ps` | Compose принимает конфигурацию. Все четыре сервиса запущены, `mc` готов |
| STAND-01-2. Бакет и запись | `bash scripts/stand-smoke.sh prepare` | Чтение возвращает `(1, trino)` и `(2, minio)` в этом порядке. Бакет приватный. В MinIO присутствуют файл Parquet и файл `.metadata.json` контрольной таблицы |
| STAND-01-3. Повторная подготовка | Повторно выполнить `bash scripts/stand-smoke.sh prepare` | Результат SELECT содержит те же две строки без дублей |
| STAND-01-4. Сохранность | Выполнить `docker compose down`, затем `docker compose up -d --wait --wait-timeout 180` и `bash scripts/stand-smoke.sh verify` | После пересоздания контейнеров доступны обе строки и физические объекты. Таблица в режиме `verify` не перезаписывается |

## Протокол прогона от 25 ноября 2026 года

Окружение — Apple M1 Pro, Docker Desktop 4.100.1, Engine 29.9.3 (Linux ARM64), Compose v5.7.1. Статические проверки YAML и Bash прошли до запуска.

|---|---|---|
| STAND-01-1 | Compose принял конфигурацию. Запущены Trino, REST Catalog, MinIO и mc. Trino сообщил `state=ACTIVE` и `starting=false` | Пройден |
| STAND-01-2 | `MERGE: 2 rows`. Прочитаны `(1, trino)` и `(2, minio)`. Политика бакета — `private`. Для таблицы найдены один Parquet-файл и два файла `.metadata.json` | Пройден |
