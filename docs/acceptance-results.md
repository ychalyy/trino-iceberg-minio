# Протокол сквозной приёмки Lakehouse

Испытания выполнены 25 ноября 2026 года на Apple M1 Pro в изолированном Compose-проекте с чистыми томами. Использованы Docker Desktop 4.100.1, Docker Engine 29.9.3, Trino 484, Iceberg REST Fixture 1.10.1, MinIO и Superset 6.1.0 на ARM64. Порядок воспроизведения приведён в [ПМИ](acceptance.md) и [ручной инструкции](manual-verification.md).

## Стенд, источник, модель и витрины

| Испытание | Фактическое свидетельство | Результат |
|---|---|---|
| STAND-01-1–4 | Четыре сервиса запущены. Первый smoke MERGE записал 2 строки, повтор записал 0. После пересоздания те же строки прочитаны, файлы Parquet и JSON сохранились в приватном бакете | Пройдено |
| SRC-02-1–2 | Загружены `region 5`, `nation 25`, `supplier 100`, `customer 1500`, `part 2000`, `partsupp 8000`, `orders 15000`, `lineitem 60175`. Объёмы совпали с источником, правила ключей и связей прошли | Пройдено |
| DV-03-1–2 | 6 Hubs, 6 Links, 8 Satellites. Логические ссылки и уникальность прошли проверки. Сверены 262 поля 34 объектов Trino со словарём. Позиция `1/1` имеет версии `0.04` и `0.05` | Пройдено |
| MART-04-1–2 | Обе сверки `MART_RECONCILE` дали 0 несовпавших групп по каждому положительному пакету. `ASIA`, 1996-01: стоимость после скидки `4809918.9692 → 4809671.8657`, разница `−247.1035` совпала с расчётом. Группы отгрузок сохранились | Пройдено |
| LOAD-05-1–2 | Остановка после записи Raw оставила опубликованным `initial`. Повтор применил `delta`, обе витрины выходят на номер 2. Повтор опубликованных пакетов сохраняет состав строк и версии | Пройдено |
| DQ-06-1–2 | `make dq` записал 33 входные и 59 модельных проверки PASS. Ошибочный вход завершился кодом 1. `DISCOUNT_RANGE / lineitem` показал `0 / 1 / FAIL`. Пакет `invalid` не опубликован | Пройдено |

Для технического прогона, который совпал с запросами Superset к каталогу, зафиксирован `SQLITE_BUSY`. Увеличено время ожидания записи SQLite и добавлен ограниченный повтор идемпотентных операций при неопределённом результате коммита. На повторе дельта и проверка качества завершились успешно. Запуски отражаются отдельными идентификаторами DQ.

## Повторный прогон финальной версии

На чистом Compose-проекте `lakehouse-submit` команда `make demo` завершилась с кодом 0. Первичный пакет, повтор, остановка после Raw, восстановление с дельтой и повтор дельты прошли последовательно. В результатах 433 PASS и один ожидаемый FAIL для диагностического пакета. Обе итоговые витрины соответствуют SQL, фактическая и ожидаемая разница продаж в ASIA за январь 1996 года одинаковы. [Контрольные значения чистого прогона](evidence/release-control-values.tsv)

## Проверка Superset

| Испытание | Фактическое свидетельство | Результат |
|---|---|---|
| BI-07-1 | ZIP успешно импортирован штатным API в чистую базу метаданных. В браузере открылись один дашборд, две вкладки, шесть визуализаций и три набора Trino | Пройдено |
| BI-07-2 | В сводке прогона было 582 PASS и 1 FAIL. Фильтры запуска, правила и статуса отобрали строку `invalid / DISCOUNT_RANGE / lineitem / 0 / 1 / FAIL`. Строка видима в таблице | Пройдено |
| BI-07-3 | Бизнес-графики и таблицы вернули данные. Выбор января 1996 года дал 5 строк продаж и 7 строк отгрузок, все даты в выбранном месяце. Фильтры MIDDLE EAST и REG AIR применились к соответствующим визуализациям. Доля REG AIR равна `4302 / 8616 = 0.49930362116991645` и совпадает с SQL | Пройдено |

После перехода на сохранённые агрегаты все четыре бизнес-визуализации ответили в браузерной проверке примерно за 3–9 секунд при локальном прогоне. Результаты дельты и состав групп сохранились.
