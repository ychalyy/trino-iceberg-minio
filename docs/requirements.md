# Краткое техническое задание

## Цель и результат

Развернуть прототип Lakehouse для анализа продаж и отгрузок на синтетических данных TPC-H. Проверяющий должен воспроизвести загрузку, проследить одно изменение до витрины и проверить его влияние на бизнес-показатели. Результат сдачи — публичный GitHub-репозиторий с кодом, моделями, документацией и протоколом выполненных испытаний.

## Требования и приёмка

| Пункт задания | ID | Требование | Критерий приёмки |
|---|---|---|---|
| 1 | STAND-01 | Docker Compose с Trino, Iceberg REST Catalog и MinIO | Запись Parquet и метаданных Iceberg в MinIO. Две контрольные строки читаются после пересоздания контейнеров |
| 2 | SRC-02 | Все восемь таблиц TPC-H с описанием ключей, связей, гранулярности и типов | Raw сходится по каждой таблице с `tpch.tiny`, `SF 0.01` |
| 3 | DV-03 | Центральная модель Data Vault 2.0 с Hubs, Links и Satellites | Логические ключи и связи сходятся с ERD и SQL. Изменение сохраняет две версии одного сателлита |
| 4 | MART-04 | Витрины продаж и отгрузок из Data Vault с описанием метрик | Все группы сходятся с независимым SQL по Raw. Затронутая группа продаж изменяется на ожидаемую сумму |
| 5 | LOAD-05 | Первичная загрузка, повторы и восстановление после остановки | Повтор не создаёт дублей. Незавершённый пакет не меняет бизнес-витрины. Дельта завершается после повторного запуска |
| 6 | DQ-06 | Проверки качества и сохранение результатов | Ключи, ссылки, ставки и сверки прошли. Ошибочное входное значение отклонено, причина сохранена |
| 7 | BI-07 | Один дашборд Superset с двумя вкладками и фильтрами | Дашборд импортируется в чистый Superset. Обе вкладки открываются, показатели и состояния подтверждены SQL |

## Границы прототипа

Один источник, последовательные пакеты и один процесс загрузки на Compose-проект. Источник синтетический. Дельта изменяет скидку одной позиции. Диагностический пакет проверяет отклонение ставки. Бизнес-аналитик исследует показатели по агрегированным витринам, технический пользователь проверяет происхождение данных и качество прогона.
